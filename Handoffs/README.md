# Handoffs

One file per work session, written at the end of the session so teammates can pick up where it stopped.

File name: `YYYY-MM-DD-<name>-<topic>.md`, for example `2026-11-17-shivraj-loom-data.md`.

Each handoff covers:

1. **What changed.** Files touched and what each change does.
2. **State.** What works, what is half done, what is broken.
3. **How to check it.** Steps to see the change in Live Server.
4. **Data.** New or changed files in `data/`, and the script command that rebuilds them.
5. **Next steps.** What the next person should do, in order.
6. **Open questions.** Decisions the team still needs to make.
